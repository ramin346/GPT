# 🛒 ShopBot — ربات فروش تلگرام با سود دلخواه

ربات فروش تلگرام که محصولات رو از API تأمین‌کننده می‌گیره، سود خودت رو روش می‌ذاره و به مشتری می‌فروشه.
دکمه‌ها همه شیشه‌ای (اینلاین) هستن و ربات خودش از گیت‌هاب آپدیت می‌شه.

## امکانات

- منوی شیشه‌ای: محصولات (صفحه‌بندی)، کیف پول، شارژ حساب، سفارش‌ها، پشتیبانی
- قیمت فروش = قیمت خرید × ضریب تبدیل × (۱ + سود٪)
- کیف پول داخلی با شارژ کارت‌به‌کارت (رسید برای ادمین میاد، با دکمه‌ی تأیید یا رد)
- ضد خرید تکراری (قفل هر کاربر) و کسر اتمیک موجودی
- برگشت خودکار پول در صورت خطای API. در صورت تایم‌اوت سفارش «نامشخص» می‌شه و به ادمین خبر می‌ده
- پنل ادمین: تغییر درصد سود، آمار فروش و سود، شارژ دستی کاربر، رفرش محصولات، آپدیت از گیت‌هاب
- **آپدیت خودکار از گیت‌هاب** (توضیح پایین)

## ساختار پروژه

| فایل | کار |
|---|---|
| `bot.py` | خود ربات |
| `updater.py` | منطق آپدیت از گیت‌هاب |
| `install.sh` | نصب روی سرور و ساخت سرویس systemd |
| `backup.sh` | بکاپ از دیتابیس |
| `.env.example` | نمونه تنظیمات (مقدار واقعی نذار) |

## ۱) آپلود روی گیت‌هاب (از کامپیوتر خودت)

ریپو رو **Private** بساز، بعد:

```bash
git init
git add .
git status          # مطمئن شو .env و *.db توی لیست نیستن
git commit -m "first version"
git branch -M main
git remote add origin git@github.com:USERNAME/REPO.git
git push -u origin main
```

## ۲) نصب روی سرور

برای ریپوی خصوصی، سرور باید به گیت‌هاب دسترسی (فقط خواندن) داشته باشه. روش پیشنهادی **Deploy Key** هست:

```bash
ssh-keygen -t ed25519 -f ~/.ssh/shopbot_deploy -N ""
cat ~/.ssh/shopbot_deploy.pub
```

متن خروجی رو توی گیت‌هاب بذار: ریپو ← Settings ← Deploy keys ← Add deploy key (تیک Write نزن). بعد این رو به `~/.ssh/config` اضافه کن:

```
Host github.com
  IdentityFile ~/.ssh/shopbot_deploy
  IdentitiesOnly yes
```

حالا کلون و نصب:

```bash
git clone git@github.com:USERNAME/REPO.git shopbot
cd shopbot
sudo bash install.sh
nano .env                      # مقادیر واقعی رو پر کن
sudo systemctl start shopbot
sudo journalctl -u shopbot -f  # دیدن لاگ
```

> ربات باید با همون کاربری اجرا بشه که کلید SSH رو داره. `install.sh` سرویس رو با کاربری که اسکریپت رو اجرا کرده (sudo) می‌سازه.

## ۳) آپدیت خودکار

هر `AUTO_UPDATE_MINUTES` دقیقه (پیش‌فرض ۱۰) ربات این کارها رو می‌کنه:

1. `git fetch` و مقایسه با `origin/main`
2. اگه نسخه‌ی جدید بود: `git merge --ff-only`
3. اگه `requirements.txt` عوض شده بود: نصب پکیج‌ها
4. تست سینتکس کد جدید. **اگه خطا داشت، خودکار به نسخه‌ی قبل برمی‌گرده**
5. صبر تا تموم‌شدن خریدهای در حال انجام، بعد ریستارت و پیام به ادمین

ادمین‌ها هر وقت خواستن با دستور `/update` یا دکمه‌ی «⬆️ آپدیت ربات از گیت‌هاب» توی پنل ادمین، دستی هم آپدیت می‌کنن.

برای خاموش‌کردن: `AUTO_UPDATE_MINUTES=0` توی `.env`.

**روند کاری بعد از این:** روی کامپیوتر کد رو تغییر بده، `git commit` و `git push` بزن. حداکثر ۱۰ دقیقه بعد (یا با `/update` فوری) روی سرور فعال می‌شه.

## بکاپ

موجودی کاربرها توی `bot.db` هست و روی گیت نمی‌ره. بکاپ خودکار روزانه با cron:

```bash
crontab -e
# اضافه کن (مسیر رو اصلاح کن):
0 4 * * * /home/USER/shopbot/backup.sh
```

## نکات امنیتی

- `.env` و `bot.db` توی `.gitignore` هستن و نباید وارد گیت بشن.
- اگه کلید API یا توکن اشتباهی توی گیت‌هاب رفت، پاک‌کردن فایل کافی نیست. همون کلید رو از پنل سایت یا BotFather عوض کن.
- چون ربات خودش کد رو از گیت‌هاب می‌گیره و اجرا می‌کنه، اکانت گیت‌هاب خودت رو با 2FA امن نگه دار.

## تنظیم با داکیومنت API

اگه فیلدهای API با حدس‌های پیش‌فرض فرق داشت، این سه جا توی `bot.py` رو اصلاح کن:
`normalize_product` (نام فیلدهای محصول)، `api_purchase` (بدنه‌ی خرید) و متغیرهای `AUTH_HEADER` و `AUTH_PREFIX` توی `.env`.
