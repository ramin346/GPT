# 🛒 ShopBot — ربات فروش تلگرام با موجودی دستی

ربات فروش تلگرام که **دسته‌ها، محصولات و موجودی (اکانت/کد) رو خودت از داخل ربات مدیریت می‌کنی**.
بعد از هر خرید موفق، یکی از آیتم‌های موجودی خودکار برای مشتری فرستاده می‌شه. دکمه‌ها شیشه‌ای (اینلاین) هستن و ربات از گیت‌هاب آپدیت خودکار می‌گیره.

## امکانات

- **دسته‌بندی دلخواه:** مثلاً Fastly، ChatGPT و ...
- **محصول داخل هر دسته:** اسم، قیمت فروش، قیمت خرید (برای محاسبه سود) و توضیحات
- **موجودی دستی:** هر خط یک آیتم (یا آیتم چندخطی با جداکننده `---`، یا فایل `.txt` برای تعداد زیاد)
- **تحویل خودکار:** بعد از خرید موفق، آیتم داخل ربات برای کاربر ارسال می‌شه (قابل کپی با یک لمس) و توی «سفارش‌های من» هم می‌مونه
- **هر آیتم فقط یک بار فروخته می‌شه:** حتی اگر چند نفر همزمان بخرن، قفل داخلی جلوی فروش تکراری رو می‌گیره
- **کیف پول داخلی:** شارژ با کارت‌به‌کارت و رسید، تأیید یا رد توسط ادمین
- **هشدار کمبود موجودی** برای ادمین
- **آمار:** تعداد کاربر، فروش کل، سود کل، موجودی باقی‌مانده
- **آپدیت خودکار از گیت‌هاب** (با برگشت خودکار در صورت خرابی کد)

## نحوه‌ی استفاده (ادمین)

1. توی ربات `/start` بزن و «⚙️ پنل ادمین» ← «📂 دسته‌ها و محصولات» ← «➕ دسته‌ی جدید» (مثلاً `ChatGPT`)
2. داخل دسته «➕ محصول جدید» بزن و اسم، قیمت فروش، قیمت خرید و توضیحات رو بده
3. داخل محصول «➕ افزودن موجودی» بزن و اکانت‌ها رو بفرست:
   ```
   user1@mail.com:pass1
   user2@mail.com:pass2
   ```
   اگر هر آیتم چند خطیه، بینشون یک خط فقط `---` بذار:
   ```
   ایمیل: a@x.com
   پسورد: 123
   ---
   ایمیل: b@x.com
   پسورد: 456
   ```
4. دسته و محصول برای مشتری‌ها نمایش داده می‌شه. محصول بدون موجودی با علامت «❌ ناموجود» دیده می‌شه.

## ساختار پروژه

| فایل | کار |
|---|---|
| `bot.py` | خود ربات |
| `updater.py` | منطق آپدیت از گیت‌هاب |
| `install.sh` | نصب روی سرور و ساخت سرویس systemd |
| `backup.sh` | بکاپ از دیتابیس |
| `.env.example` | نمونه تنظیمات (مقدار واقعی نذار) |

## نصب روی سرور

```bash
git clone https://github.com/USERNAME/REPO.git shopbot
cd shopbot
cp .env.example .env
nano .env                      # BOT_TOKEN، ADMIN_IDS، شماره کارت و ...
sudo bash install.sh
sudo systemctl start shopbot
sudo journalctl -u shopbot -f  # دیدن لاگ
```

> اگر فایل‌ها رو از طریق سایت گیت‌هاب آپلود کردی، مطمئن شو اسم `.env.example` و `.gitignore` درست باشه (نه `_.env.example`).

## آپدیت خودکار

هر `AUTO_UPDATE_MINUTES` دقیقه (پیش‌فرض ۱۰) ربات گیت‌هاب رو چک می‌کنه، نسخه‌ی جدید رو می‌گیره، کد رو تست سینتکس می‌کنه (در صورت خطا به نسخه‌ی قبل برمی‌گرده) و ریستارت می‌شه.
ادمین هر وقت بخواد با `/update` یا دکمه‌ی «⬆️ آپدیت ربات از گیت‌هاب» فوری آپدیت می‌کنه. خاموش‌کردن: `AUTO_UPDATE_MINUTES=0`.

## بکاپ

دیتابیس (`shop.db`) شامل کیف پول کاربرها، محصولات و **موجودی فروش‌نرفته** هست و روی گیت نمی‌ره. بکاپ روزانه با cron:

```bash
crontab -e
0 4 * * * /home/USER/shopbot/backup.sh
```

## نکات امنیتی

- `.env` و `*.db` توی `.gitignore` هستن و نباید وارد گیت بشن.
- چون موجودی (اکانت‌ها) توی دیتابیس سرور ذخیره می‌شه، دسترسی سرور و فایل `shop.db` رو امن نگه دار.
- چون ربات کد خودش رو از گیت‌هاب می‌گیره، اکانت گیت‌هاب رو با 2FA امن کن و برای شاخه‌ی `main` محافظت (Branch protection) فعال کن.
